# 华夏纪年 · Huaxia Chronicle

> 沿时间长河，探索中国历史的文明与变迁

**在线访问：<https://2089508727.github.io/huaxia-jinian/>**

## 简介

华夏纪年是一个交互式中国历史网站：朝代时间轴、历史人物与事件图鉴、历史地图、年份探索与朝代比较，并内置"历史地图挑战"小游戏。

- 56 个政权与阶段
- 111 位历史人物
- 153 个历史瞬间

## 技术说明

整个网站打包为**单个 HTML 文件**（`index.html`，约 16 MB），样式、脚本、数据、字体与图片均内联，无外部依赖，可直接双击打开或静态托管。

## 部署

- 托管：GitHub Pages（`main` 分支根目录）
- 更新方式：替换仓库根目录的 `index.html` 即可，Pages 会自动重新构建
